# Contribuir

Use Python 3.12. Crie um ambiente com `python instalar.py` e execute os testes com o Python de `.venv`:

```sh
python -m unittest discover -s tests -v
```

Abra uma issue descrevendo a necessidade antes de mudanças extensas. Envie correções em uma branch e explique problema, solução e testes no pull request. Use dados sintéticos; não inclua PDFs reais ou históricos institucionais. Testes não devem depender de catálogos públicos disponíveis ao vivo.

As três entradas de trabalho devem continuar independentes. Preserve os códigos de saída e a separação entre processamento, SAF gerado e cadastro confirmado. Não marque itens como concluídos antes da validação de seus arquivos.
