# Autoria e distribuição

Esta versão deriva dos scripts fornecidos pelo responsável pelo projeto. Nenhuma licença foi atribuída automaticamente em nome dos autores. Antes de apresentar o projeto como open source, o responsável deve definir a licença e confirmar a autoria/permissões dos componentes reaproveitados.

O fonte do SAFBuilder, PDFs, metadados institucionais e capturas reais não integram este pacote público. A integração opcional com um JAR externo permanece disponível; obtenha-o do fornecedor e observe suas condições de uso. Referência do projeto: https://github.com/DSpace-Labs/SAFBuilder

As dependências Python conservam suas próprias licenças. O pacote não incorpora seus binários. A decisão de licença para o projeto deve ser registrada em LICENSE pelo responsável; não há um LICENSE fictício ou com titular inventado nesta entrega.
